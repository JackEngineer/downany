# Trae 视频下载器 - 增强版

基于 Python、yt-dlp 和 PyQt6 的现代化视频下载应用，支持多平台、队列管理、搜索功能等。

## 新增功能

### 🎯 核心功能

1. **平台识别**
   - 自动识别 YouTube、Bilibili、抖音、TikTok、Twitter、Instagram 等平台
   - 显示平台图标和颜色标识

2. **平台搜索**
   - 在 YouTube 和 Bilibili 内搜索视频
   - 显示搜索结果列表（标题、上传者、时长）
   - 直接从搜索结果添加到下载队列

3. **队列管理**
   - 支持多任务并发下载（可配置并发数，默认3个）
   - 任务状态管理：等待中、下载中、已暂停、已完成、失败、已取消
   - 实时显示下载进度、速度、剩余时间
   - 支持暂停/恢复/取消/重试操作

4. **历史记录**
   - SQLite 数据库存储下载历史
   - 支持搜索历史记录（标题、链接、上传者）
   - 可重新下载历史记录中的视频
   - 可删除历史记录

5. **高级设置**
   - 自定义下载目录
   - 配置并发下载数（1-10）
   - 速度限制（KB/s）
   - 代理配置（HTTP/HTTPS）
   - 默认质量选择（best、1080p、720p、480p、360p）
   - 自动下载字幕

6. **现代化 UI**
   - 扁平化设计
   - 圆角卡片
   - 柔和配色
   - 标签页布局（搜索、下载、队列、历史、设置）

## 架构说明

### 核心模块

```
src/
├── core/
│   ├── download_manager.py      # 队列管理器（并发控制、任务调度）
│   ├── download_task.py         # 任务模型（状态机、VideoInfo）
│   ├── downloader.py            # yt-dlp 封装
│   ├── platform_detector.py     # 平台识别
│   ├── video_info_extractor.py  # 视频信息提取
│   └── search_engine.py         # 平台搜索
├── data/
│   ├── database.py              # SQLite 历史记录
│   ├── models.py                # 数据模型
│   └── config_manager.py        # 配置管理（QSettings）
├── ui/
│   ├── main_window.py           # 主窗口（标签页布局）
│   ├── tabs/
│   │   ├── search_tab.py        # 搜索标签页
│   │   ├── download_tab.py      # 下载标签页
│   │   ├── queue_tab.py         # 队列标签页
│   │   ├── history_tab.py       # 历史标签页
│   │   └── settings_tab.py      # 设置标签页
│   └── styles/
│       └── theme.py             # 主题定义（QSS）
└── utils/
    └── logger.py                # 日志工具
```

### 数据存储

- **配置文件**: `~/Library/Preferences/com.Trae.Downloader.plist` (macOS)
- **历史数据库**: `~/.trae_downloader/history.db` (SQLite)

## 使用说明

### 启动应用

```bash
# 方式 1: 使用 npm start
npm start

# 方式 2: 直接运行
source venv/bin/activate
python src/main.py
```

### 功能使用

1. **搜索视频**
   - 切换到"搜索"标签页
   - 选择平台（YouTube 或 Bilibili）
   - 输入关键词并点击"搜索"
   - 双击或选中后点击"下载选中"添加到队列

2. **直接下载**
   - 切换到"下载"标签页
   - 输入单个视频链接或批量链接（每行一个）
   - 点击"开始下载"或"开始批量下载"

3. **管理队列**
   - 切换到"队列"标签页
   - 查看所有任务的状态和进度
   - 选中任务后可以暂停/恢复/取消/重试

4. **查看历史**
   - 切换到"历史"标签页
   - 搜索或浏览下载历史
   - 可重新下载或删除记录

5. **配置设置**
   - 切换到"设置"标签页
   - 配置下载目录、并发数、速度限制等
   - 点击"保存设置"

## 技术特性

### 下载管理

- **并发控制**: 使用线程池控制并发下载数
- **任务调度**: 后台调度线程自动分配任务
- **状态管理**: 完整的任务状态机（PENDING → DOWNLOADING → COMPLETED/FAILED）
- **进度回调**: 实时更新下载进度、速度、剩余时间

### 暂停/恢复

- **实现方式**: 伪暂停（取消下载 + 保存状态）
- **恢复机制**: 重新开始下载（yt-dlp 会自动续传部分下载的文件）
- **注意**: 不是真正的暂停，可能会浪费少量流量

## 注意事项

1. **首次运行**: 会自动创建配置文件和数据库
2. **FFmpeg**: 建议安装 FFmpeg 以支持音视频合并
3. **代理**: 某些平台可能需要配置代理才能访问
4. **并发数**: 建议不要设置过高，避免被平台限制
5. **速度限制**: 0 表示无限制
