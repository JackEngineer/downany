# Chrome 扩展：媒体识别 + 一键入队

识别当前页面中的多媒体（DOM + 网络嗅探），勾选后发送到本机 **百纳**（Electron）。优先走本机 HTTP 桥 `127.0.0.1:17888`（可携带 Referer/Cookie），失败再回退 `downany://`。

纯嗅探逻辑在 `sniff-core.js`（无 Chrome API），桌面端 `desktop/electron/mediaSniff.ts` 与之对齐，便于复用清单解析与 URL 分类。

## 必做：改完代码后重新加载

1. 确认 **Electron 下载器正在运行**（桥才会监听）
2. 打开 `chrome://extensions` →「百纳」→ 点 **重新加载**（版本应为 0.6.0）
3. 打开视频页并**播放** → 悬停视频点「下载」，或点工具栏图标 → 勾选媒体 →「下载选中」

首次加载会申请访问所有网站的权限（用于网络嗅探与读取 Cookie）。

## 最快用法

```bash
# 终端 1：下载器
cd desktop && DOWNANY_PYTHON="$(pwd)/../venv/bin/python" npm run dev

# 终端 2（可选）：重启 Chrome 并加载扩展
./scripts/setup_chrome_extension.sh
```

然后在扩展页再点一次 **重新加载**。

## 用法

| 操作 | 效果 |
|------|------|
| 悬停页面视频 → 点右上角「下载」 | 页内一键入队（详情页站点发页面链接，其他站点发最佳流） |
| 点击工具栏图标 | 弹出媒体列表 → 勾选 →「下载选中」 |
| 「下载本页视频（推荐）」/「仅发送页面链接」 | 把当前页 URL 交给 yt-dlp；抖音精选 `modal_id` 会自动改写成 `/video/{id}` |
| 右键页面 / 链接 / 选中 URL / 音视频 | 直接发送（不弹窗） |
| 弹窗底部「页内下载按钮」 | 开关页内悬浮按钮（默认开启） |

成功时弹窗会显示「已发送」；下载器应跳到队列并 toast。若提示桥未连接，先打开下载器。

角标数字 = 当前标签页已识别到的媒体数量。

## 抖音说明

- 精选/发现页（`jingxuan?modal_id=` 等）会归一成 `douyin.com/video/{id}` 再交给 yt-dlp
- 切换下一条视频（SPA 改 `modal_id`）会自动清空上一条的嗅探结果，并刷新标题
- 扩展会带上浏览器里的 `douyin.com` Cookie；若仍报需要新鲜 Cookie，在浏览器刷新抖音页后再试
- 「页面解析」条目显示当前视频标题，不再用 CDN 预览片体积误导；点「下载本页视频（推荐）」即可

## 识别原理

- **DOM 扫描**：`<video>` / `<audio>` / `<source>` / `og:video` 等
- **网络嗅探**：拦截页面请求中的 `.m3u8` / `.mpd` / `.mp4` / `.webm` / 音视频 Content-Type
- **有效性验证**：清单（m3u8/mpd）必须真实拉取并解析成功才入列（同时读出时长/清晰度）；无大小信息的文件会发 Range 请求验证确实是媒体；过期、404、非媒体内容直接丢弃
- **多码率归并**：同一视频的多个清晰度清单合并为一条（master 优先）
- **过滤**：丢弃 `.ts` / `.m4s` 等分片与小于 100KB 的装饰性音视频（头像/emoji/广告碎片）
- **发送前复核**：媒体地址多带时效签名，发送前再验证一次，已过期的自动跳过并提示，不会把无效任务塞进下载器
- **请求头**：发送时现场拼装 `Referer`（页面 URL）与页面域 + 媒体域 `Cookie`，经本机桥传给下载器

许多站点必须先**播放视频**，真实流地址才会出现在网络请求里。

已识别的媒体会写入会话存储，即使扩展后台脚本被浏览器休眠回收，打开弹窗时仍能找回。

## 手动安装（持久）

### Google Chrome

1. `chrome://extensions` → 开发者模式
2. 加载已解压 → 选本目录 `browser-extension/`
3. 固定工具栏图标

### Microsoft Edge（Chromium / MV3）

1. 打开 `edge://extensions`
2. 开启 **开发人员模式**
3. **加载解压缩的扩展** → 选择本目录 `browser-extension/`
4. 固定扩展图标；用法与 Chrome 相同（HTTP 桥 + `downany://` 回退）

### Mozilla Firefox（MV3 临时加载）

Firefox 对 Manifest V3 的支持因版本而异；开发调试可用临时加载：

1. 打开 `about:debugging#/runtime/this-firefox`
2. **临时载入附加组件…** → 选择本目录下的 `manifest.json`
3. 重启浏览器后需重新加载（临时附加组件不持久）
4. 若网络嗅探或 `contextMenus` 权限异常，请优先使用 Chrome/Edge；Firefox 正式上架待后续适配

## 说明

- 需要下载器运行（或至少协议已注册）
- 非 http(s) 页（如 `chrome://`）无法发送
- Cookie 仅经 `127.0.0.1` 本机桥传递，不上传到外部服务器
