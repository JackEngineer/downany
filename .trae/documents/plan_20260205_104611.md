# 优化界面与增加批量下载功能计划

本计划旨在通过重构 UI 布局来提升用户体验，并新增批量下载功能以满足多视频下载需求。

## 1. 界面优化 (UI Layout & Design)

我们将使用 `QTabWidget` 将界面划分为两个主要功能区，并优化控件布局和样式。

### 1.1 总体布局重构

* **主容器**: 使用 `QTabWidget` 替代单一的垂直布局。

* **Tab 1: 单个下载 (Single Download)**: 保持现有功能的精简版，优化输入框和按钮的间距。

* **Tab 2: 批量下载 (Batch Download)**: 新增功能区。

* **公共区域**: 底部保留“保存目录”选择和“全局日志/状态栏”，因为这通常是通用的。

### 1.2 视觉样式优化

* 使用 `QGroupBox` 对“下载设置”进行分组，增加视觉层次感。

* 增加控件间的 Padding 和 Spacing，避免界面过于拥挤。

* 为按钮添加图标（使用 Unicode 字符或标准图标）和简单的 QSS 样式（如圆角、悬停效果）。

## 2. 批量下载功能 (Batch Download)

### 2.1 UI 实现

* **输入方式**: 在“批量下载” Tab 中添加 `QTextEdit`，允许用户输入多行 URL（每行一个）。

* **进度展示**:

  * **总进度**: 显示 "正在下载第 X/Y 个视频"。

  * **当前进度**: 复用现有的进度条显示当前文件的下载进度。

  * **任务列表**: 使用 `QTextEdit` 或 `QListWidget` 显示下载队列的状态（完成/失败/进行中）。

### 2.2 核心逻辑调整

* **`DownloadThread`** **类改造**:

  * 修改 `__init__` 方法，使其接受 URL 列表 (`List[str]`) 而非单个字符串。

  * 在 `run` 方法中遍历 URL 列表，依次调用 `Downloader`。

  * 增加新的信号或扩展现有信号，以通知主界面“当前正在下载第几个文件”。

## 3. 实施步骤

1. **修改** **`src/ui/main_window.py`**:

   * 引入 `QTabWidget`, `QGroupBox`, `QTextEdit` 等新组件。

   * 重构 `init_ui` 方法，建立 Tab 结构。

   * 实现批量 URL 解析逻辑（按行分割，去空）。
2. **更新** **`DownloadThread`**:

   * 支持 URL 列表处理。

   * 添加“任务切换”的逻辑，确保 UI 能更新“正在下载 X”的状态。
3. **验证**:

   * 测试单个下载是否正常。

   * 测试批量下载（输入 2-3 个链接），验证队列执行和进度条重置逻辑。

## 4. 预期效果

* 界面更加整洁、专业。

* 用户可以一次性粘贴多个链接进行下载。

* 下载过程中有清晰的进度反馈（总体进度 + 单个文件进度）。
