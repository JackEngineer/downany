# 解决视频下载报错问题

## 问题分析

用户在下载视频时遇到报错 `ERROR: You have requested merging of multiple formats but ffmpeg is not installed.`。
这是因为 `yt-dlp` 下载高清视频时通常会分开下载视频流和音频流，下载完成后需要使用 `ffmpeg` 将它们合并。如果系统中没有安装 `ffmpeg`，就会导致合并失败。
此外，日志中还包含一个警告 `WARNING: [youtube] No supported JavaScript runtime could be found.`，建议安装 `deno` 以提高解析稳定性。

## 解决方案

我们将通过以下步骤修复此问题：

### 1. 安装系统依赖

在 macOS 上使用 Homebrew 安装缺失的依赖：

* `ffmpeg`: 用于处理音视频合并。

* `deno`: 用作 JS 运行时，解决 `yt-dlp` 的警告。

### 2. 更新环境安装脚本

修改 `scripts/install_env.sh`，使其在检测到 macOS 环境且安装了 Homebrew 时，自动尝试安装或提示安装 `ffmpeg` 和 `deno`。

## 执行步骤

1. 运行 `brew install ffmpeg deno` 安装依赖。
2. 修改 `scripts/install_env.sh` 添加自动安装逻辑。
3. 验证安装是否成功。
