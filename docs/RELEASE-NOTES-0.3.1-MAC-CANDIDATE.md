# Downany 0.3.1 Mac 候选版

面向 Apple Silicon Mac 的候选交付，配套 Chrome 插件 0.9.2。该交付未满足原计划的完整网站可靠性验收，应标记 GitHub Pre-release，不设为 Latest；当前稳定版仍为 v0.3.0。

## 变化

- 下载输出合同、文件名与安全落盘处理改进，保留队列状态与设置。
- 浏览器抓取区分当前页与历史媒体，任务列表和历史支持统一排序。
- 插件区分检测媒体与网页解析，批量发送保留回执并防重复；视频/音频输出及网页清晰度上限偏好分别处理。
- 抖音网页信息读取失败不再误判未登录，提示登录状态未知，并引导现有浏览器抓取流程；不读取或导出 Chrome 凭据。

## 验证

最终源码回归：Python 1072通过、3跳过；桌面642通过；脚本355通过、4跳过；生产构建与类型检查通过。Mac安装包内资源与最终源码编译一致；本机隔离空数据应用启动、首次本地媒体下载与完整解码通过；真实0.3.0到0.3.1包内队列升级经历5轮中断/正常退出，10条队列保留、6个输出完整解码通过。这些是隔离工程验证，不是另一台干净Mac或Gatekeeper人工首次打开证明。

普通Chrome弹窗已确认插件0.9.2实际加载并连接。完整批量原生交互记录属于0.9.1；0.9.2新失败任务提示流程未完成完整原生验收，不挪用旧结果。

## 已知限制

- 当前网站实测只完成YouTube与Bilibili各一个授权影片成功下载，抖音自有公开作品的匿名解析失败；完整三站矩阵及授权对照未完成，不宣称90%成功率。
- 抖音抓取需网站实际提供可用媒体；登录状态未知或网页可播放不保证详情接口允许下载。没有当前候选授权抓取成功证明。
- Mac包未使用Developer ID签名或公证，首次打开可能遇到Gatekeeper提示；本轮不修改系统安全设置或绕过拦截。
- 仅Mac arm64，Windows不属于本轮交付。应用更新仅检查正式Release并引导下载，不自动替换安装。
