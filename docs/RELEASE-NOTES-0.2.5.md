# Downany · 百纳 v0.2.5

状态：Windows 本地候选，尚未公开发布。

## 队列更可靠

- 等待中的任务也能暂停；重启后仍保留你的暂停选择。
- 继续任务时会等待上一次下载退出，避免同一任务重复运行。
- 意外退出后恢复原有任务和顺序；失败或已取消的任务仍由你决定是否重试。
- 整组和全部操作会显示实际处理数量；保存失败时不会留下只改了一部分的队列。

## 长队列更清楚

- 支持在同一优先级内上移、下移或移到顶部；搜索结果中的分组操作也会移动完整分组。
- 同一分组的未完成任务保持连续，优先级一起调整；已完成记录不变。
- 进度集中更新，减少长队列的重复刷新；完成、失败和移除结果不会被延迟进度覆盖。
- 分组、全部操作和调整顺序后，已完成或已移除的任务不会被稍晚返回的旧队列信息恢复。

## 下载和发送互不干扰

- Telegram 发送失败或结果待确认，不会把已完成下载变成失败，也不会自动重新下载。
- 重试发送和取消待发送项目不会改动下载成品。

## 候选范围与限制

- 本轮仅提供 Windows x64 本地候选与 Chrome 扩展；扩展继续使用独立版本 `0.8.2`。
- Windows 候选沿用未签名、Telegram 云端模式；未启用 Telegram 本地大文件发送模式。
- 以自动化测试和隔离包级检查为验证依据，结果见 [验证记录](acceptance/v0.2.5-queue-recovery-stability.md)。按用户要求不做人工安装或系统重启验收，也不声称这些检查已通过。
- 未改变默认单链接下载语义，也不引入新的下载引擎或自动重试策略。
- 本地候选不等于已授权发布；合并、推送、标签、远程构建与公开发布均未执行。
