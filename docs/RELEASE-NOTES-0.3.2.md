# Downany 0.3.2 候选版

Windows x64 与 Apple Silicon Mac 的发布准备版本，配套 Chrome 扩展 0.9.2。当前保持候选状态；完整网站与人工安装验收尚未完成，不能据此宣称正式发布或三站 90% 成功率。

## 变化

- 任务和下载记录的排序偏好在重启后保留。
- 任务暂时无法移除时会显示提示，方便稍后重试。

- Windows 启动参数或下载工具检查失败时，中文诊断按 UTF-8 输出，避免早期错误信息乱码。
- 下载工具更新更严格地检查压缩包原始路径，拒绝含反斜杠、空字符或盘符的成员，校验失败继续使用已有可用引擎。
- 保留 0.3.1 的下载失败处理、重试选项、队列恢复与扩展 0.9.2 功能。

## 交付与验证

安装包采用 cloud-only 模式，Telegram 走官方云端 Bot API；不宣称原生本地 Bot API 的 2 GB 能力。应用内更新仍查询正式 Release 并打开下载页。

候选构建与验收进度见 [0.3.2 发布准备记录](acceptance/v0.3.2-release-readiness.md)。正式交付需同一 annotated tag 的成功 CI 产出 Mac DMG、Windows NSIS 和扩展 ZIP，并重新下载核验草稿与公开资产。当前源码清单中的空值表示尚未生成的资产，不能挪用 0.3.1 的校验和。

## 已知边界

- Windows 安装包未签名，Mac 未使用 Developer ID 签名或公证，首次安装/打开可能遇到系统安全提示；本轮不修改安全设置或绕过拦截。
- 完整授权网站矩阵、登录前后对照、普通 Chrome 原生扩展操作和最终人工安装记录尚未完成。
- 五人首次使用者试用已按现行 Windows 交接要求取消；其他真实验收要求仍保留。
