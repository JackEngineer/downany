**最需要优先处理的五类问题**：

1. **下载失败会被标记为"已完成"**（异常被吞掉，状态机被污染，历史记录随之出错）
2. **取消/暂停名不副实**（Python 版暂停后下载继续跑；恢复可能双线程并发写同一任务）
3. **多线程共享状态完全无锁**（调度器、队列、任务字典跨线程读写无同步原语）
4. **窗口关闭不清理后台资源**（搜索线程、预览播放器、缩略图请求、定时器均可能在 UI 销毁后回调）
5. **仓库卫生失控**（约 39 个 `.pyc`/`.DS_Store` 已入库、76MB x86_64 ffmpeg 二进制进 Git、无 CI、文档严重过时）
