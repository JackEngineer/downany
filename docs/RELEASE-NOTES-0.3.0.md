# Downany · 百纳 v0.3.0

状态：已通过自动化门槛与独立只读审查，提交并合入本地 main；Windows 已从 0.2.4 升级至 0.3.0，安装与数据保留检查通过。尚未推送、打标签或公开发布。

## 任务和设置更可靠

- 启动、重连和操作后的刷新，不再用迟到的结果覆盖刚完成、移除或调整过的任务。
- 保存设置期间继续编辑时保留最新输入；较早的保存结果不会把新输入改回去。
- 操作已成功而列表暂时未更新时，分别说明结果，避免误以为失败而重复执行。
- 诊断包已保存但文件夹打不开时保留成功结果；打开文件、更新检查等失败显示明确提示。

## 关键操作支持中英文

- 添加确认、任务状态、暂停/恢复/重试、合集、排序、更新与诊断使用一致语言。
- 在一个窗口切换语言，其他已打开窗口的关键界面也会更新；不改写你的标题或链接。
- 设置分类在较窄窗口中换行，保留所有入口。
- 不是全界面翻译：部分低频设置、原生菜单及服务端历史说明仍为中文。

## 兼容与交付范围

- 沿用 v0.2.5 的暂停意图、队列恢复、成品校验和下载/Telegram 发送结果分离。
- 分别验证实际 v0.2.5 包数据与 v0.2.1 旧源码格式 fixture，不把格式测试描述成旧安装器升级。
- 仅 Windows x64 本地候选与 Chrome 扩展 `0.8.2`；沿用未签名、Telegram 云端模式。
- 不改变默认单链接下载，不引入自动安装、自动重试发送或新下载引擎。
- 按用户要求不做人工验收和 Mac 工作；安装后以隔离数据验证真实程序启动、Sidecar 与浏览器入队，不触发用户原有任务或真实发送。结果见 [候选验证](acceptance/v0.3.0-stable-baseline.md) 和 [本地集成与安装记录](acceptance/v0.3.0-windows-local-integration.md)。
