# 0.3.8 Mac 抖音公开解析修复与原样本定位

日期：2026-10-14。实际安装桌面/Sidecar均0.3.8，已原生UI下载和完整音视频验收。未推送/发布或操作Windows。

## 已修复问题

旧匿名抖音任务只依赖yt-dlp的web detail接口，即使其他官方公开接口已返回正确视频，也没有可用解析路径。新单任务none模式请求官方分享站slides接口，严格匹配aweme_id后取平台原样返回的可信HTTPS媒体，复用原有yt-dlp暂存、后处理、成品核验、同ID恢复与不覆盖逻辑。解析确认与直接添加均接入；不会将登录来源失败静默改为匿名，继承来源、短链/合集既有路径保持。

新模块src/core/douyin_public.py：一次请求、15秒上限、2MiB响应上限、不跟随重定向、不加载或导出浏览器/Cookie文件；过滤、验证或明确HTTP拒绝即终止，不换另一作品或循环CDN。只有唯一匹配的目标视频和真实标题可入下载；HTTPS地址限制在已观察到的平台媒体域，无端口、用户信息或任意外域。画质从返回地址选择，不改媒体URL、协议、签名或去水印参数。合集/图片不误当单视频。查询签名地址不进入此验收证据。

## 本机Hermes的真实方法

已在用户指定Mac只读找到 /Users/jacklee/.hermes/skills/douyin-download/SKILL.md。它是内嵌Playwright代码而非默认yt-dlp：先打开抖音首页建立新访客会话，后请求aweme/detail，加aid=1128、cookie_enabled=true、platform=webapp，再取download_addr/play_addr用curl下载。Hermes环境 /Users/jacklee/.hermes/hermes-agent/venv/bin/python 的Playwright1.62.0；已装独立yt-dlp2026.02.04和you-get0.4.1743，you-get源码使用旧web/api/v2/iteminfo。

没有执行未知脚本、读取Hermes私密会话、密钥、env或Cookie数据库；只读目标技能及相关依赖版本。本次未照搬技能的Cookie导出与拒绝后切地址做法。

Hermes文档精确移动UA/home-first在新临时Chrome中对原作品详情返回403，停止该路线。第一次Python Playwright启动因为所需缓存1234缺失失败，非网站失败；按既有技能回退已安装Chrome新临时profile，未安装或更新浏览器、使用用户profile或访问扩展管理页。原生桌面新会话的同参数home-first对原ID返回200但缺aweme_detail，对明确独立公开作品7676036453872274731返回200和匹配详情/真实地址。因此“其他抖音视频可下载”与“此原样本当前是否可公开获取”是不同证据，不能泛称抖音无法下载。
