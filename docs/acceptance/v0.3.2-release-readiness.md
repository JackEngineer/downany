# Downany 0.3.2 发布准备记录

日期：2026-10-10。状态：候选准备，尚未公开。桌面与 Sidecar 版本 0.3.2，Chrome 扩展 0.9.2，模式 cloud-only。

## 来源与保留

以 Windows 交接源码 `01442b6eed08c8ff2f5fdf6bdc26acfe85f9f6e0` 为基线，在独立工作区 `fix/windows-v032-release` 中修复 Windows 验收问题。原工作区的六份未提交规划文档与安全 stash 保留，不包含在本次提交中。已有 v0.3.1 Mac 预发布不改动；本版本使用新的候选身份。

## 已完成的源码预检

- Windows 压缩包路径测试已用真实原始非法路径重现问题，保留完整更新校验和回退要求，修复后相关 43 项通过。
- Sidecar 将既有 UTF-8 初始化移到参数和引擎校验之前；入口/协议相关 24 项在无 UTF-8 环境覆盖下通过。
- Node 20 新依赖安装、生产构建与类型检查通过，桌面 79 文件 / 642 项通过，扩展 5 组、布局单元 12 项通过。
- 网站审核单元测试使用显式合成输入；默认正式审核依然缺数据即失败，合成输入不能用于网站验收。
- 辅助脚本最终 444 通过 / 0 失败 / 2 明确跳过：本机缺 ZIP 工具与 Windows 无符号链接权限。跳过项未被视作真实验收通过。
- 完整 Python 最终 1076 通过 / 0 失败 / 3 平台跳过，160.07 秒，实际 cp936 / UTF8Mode=0 且无 UTF-8 环境覆盖，媒体集成强制执行，原资源矩阵时限保留。跳过为一项无符号链接权限、两项 Windows 无 SIGTERM 行为。此前旧版本断言和临时目录过长的 fixture 初始化失败已分别处理并保留日志；不篡改产品断言或测试时限。
- 人工验收评估器支持显式 0.3.2 版本，默认历史 0.3.1 合同保留；84 项通过，空的新模板仍拒绝通过。
- NSIS 验收新增卸载后注册项、协议、快捷方式、进程和六个关键程序文件的有界检查，保留安装器缓存单独报告；89 项通过（安装/卸载命令为 mock，原生 read-only probe 实跑）。重解析点拒绝清理的真实隔离测试保住了外部哨兵文件；不是日常机器安装验收。
- CI 从同源版本合同读取安装器、扩展、清单和升级报告路径；匹配 tag 的实际版本步骤执行成功，错配 tag 被拒绝。

## 待完成的真实验收

Windows 交接要求的最终人工安装、系统安全提示、播放、`downany://`、普通 Chrome 扩展入队、退出及卸载记录仍需真实执行。完整三站各 10 条授权独立素材与登录对照尚未齐全；两套系统结果不得互相替代。研究出的公开素材目录只作候选，不作通过结果。

当前机器有日常 Downany 安装与注册状态，NSIS 预检拒绝运行；不删除已有安装、不清理注册表、不绕过预检。云端隔离自动工程证据不能直接填写成人工安装记录。原生 Computer Use 初始化两次均因 `helper_unknown_error` 失败，尚无原生窗口输入，普通 Chrome 弹窗验收仍未完成。

最终人工记录可以复制 [空模板](v0.3.2-manual-acceptance.template.json)，用 `node scripts/evaluate_v031_manual_acceptance.mjs <本地真实记录.json> --expected-version=0.3.2` 评估。空模板不是通过证据。
