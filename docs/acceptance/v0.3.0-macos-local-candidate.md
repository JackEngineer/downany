## 签名、公证与未完成项

- `electron-builder.yml` 明确 `identity: null`。主可执行文件只有 ad-hoc/linker 签名，无 TeamIdentifier；`codesign --verify --deep --strict` 和 `spctl --assess` 均拒绝该应用。没有 Developer ID 签名、Hardened Runtime 有效签名链、公证或 staple 证据。
- 未签名 DMG 仍会触发 Gatekeeper；本轮没有修改系统安全设置，也没有用 `xattr` 绕过后再冒充签名验收。
- 未进行拖拽安装、从 `/Applications` 首启、人工窗口操作、真实浏览器扩展、真实网站下载、真实 Telegram 账号、睡眠唤醒、重启或另一台干净 Mac 验收。
