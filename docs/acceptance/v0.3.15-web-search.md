## 产品行为

统一平台选择明确分组并在选项中标注搜索方式：应用内搜索为YouTube、Bilibili；网页搜索为X、抖音、快手。网页方式按钮为“浏览器搜索”并显示外链图标，正文明确在浏览器完成登录/验证。没有添加伪造应用内结果、视频播放器、爬虫或付费API。

官方域名入口按用户输入编码：

- X：https://x.com/search?q=<encoded>&src=typed_query&f=video
- 抖音：https://www.douyin.com/search/<encoded>?type=video
- 快手：https://www.kuaishou.com/search/video?searchKey=<encoded>

query先trim，每个平台使用encodeURIComponent编码为一个组件，保留中文、空格、斜线、&、?、#、+和emoji的真实搜索内容，不能注入路径、额外查询参数或fragment。空输入不打开；Enter支持；打开中的同步锁及同URL 1.2秒防连击避免双击重复启动。浏览器打开失败可显式重试；陈旧错误不覆盖新平台/查询。网页搜索不依赖下载服务连接，不发送search.query。应用内取消、失败重试、请求身份和迟到结果隔离保持。

“导入作品链接”只显式打开既有新建下载对话框。用户自行复制所选作品链接、手动粘贴后按Enter/解析链接；确认前不创建任务，开始下载仍由用户明确操作。不自动读取剪贴板，不预读Cookie或浏览器登录资料，不创建凭证或改变权限。用户返回后平台、关键词保持；原对话框保留自己的草稿，取消解析/关闭不会产生迟到任务，焦点回到导入按钮。文案明确部分作品可能需要登录或不支持下载，不承诺所有作品可下载。

## 真实外站核实与限制

使用新建无登录Chrome上下文直接访问这三个官方搜索地址，没有读取用户资料或处理登录、验证码。X帮助中心说明关键词搜索和视频筛选，https://help.x.com/en/using-x/x-search；官方X搜索URL当前请求被拒绝（浏览器ERR_HTTP_RESPONSE_CODE_FAILURE，web读取403）。抖音搜索地址保留查询路径和type=video、HTTP200，但标题为“验证码中间页”。快手搜索地址返回HTTP200、站点result=2错误JSON；官方首页也返回同类错误，当前网络没有正常搜索DOM。

已核对目标官方域名、编码和应用实际发出的URL，并记录真实访问结果；受上述限制，尚不能独立确认当前环境中三个站点的正常结果页/关键词回显，更不能宣称三个平台端到端下载通过。搜索URL可在用户日常浏览器中打开，实际结果、登录和验证仍受平台控制。没有通过更换代理、导入Cookie或绕过验证来补成成功。
