# Chrome 0.9.4 本人三项最小验收

候选桌面/服务0.3.6、插件0.9.4。管理页及跨应用访问限制仍有效，由本人在普通Chrome界面执行。代理不自动加载或绕过权限，不改系统安全/网络设置，不要求截图、Cookie或验证码。

## 准备

正常加载/重载本地目录stable-r13/extension-0.9.4-unpacked。仅启用一份百纳0.9.4；已有旧份可本人停用，避免两个插件同时发送。确认弹窗版本0.9.4，桌面与服务0.3.6。若浏览器或网站阻止访问，记录提示并停止对应项。

| 矩阵行 | 最小操作 | 通过标准 |
| --- | --- | --- |
| chrome-connect | 普通方式打开百纳，再打开插件弹窗。 | 百纳已连接；插件0.9.4、桌面0.3.6、服务0.3.6。 |
| chrome-reconnect | 没有进行中任务时正常退出百纳，观察插件；普通重开百纳，点重连。 | 退出期间显示未连接/启动，不误称未安装；重开后已连接，原任务与历史保留。 |
| chrome-delivery | 正常播放授权视频，打开插件，只选一种路由：解析本页视频，或选中检测媒体。记录桌面任务数，再快速双击一次发送按钮。查看回执并等待任务终态。 | 仅增加1个任务，回执定位同一ID；正确目标标题/文件名，完成并有可定位非零成品。完整解码由代理在授权本机后续核验。 |

可以使用此前公开Blender样本[Caminandes 3: Llamigos](https://www.youtube.com/watch?v=SkVqJ1SGeL0)，或本人确认有权访问且可播放的页面。遇到登录、验证或403，记录实际提示，该项不记通过，不连续重复发送。回执成功不等于下载完成；失败时保留原任务，不清空历史或删除原成品。

首次只选择一种路由。另试第二种路由属于第二个明确下载意图，不能把它的新增任务当作重复点击bug。

## 文字回报

- 连接：插件版本__，桌面__，服务__，状态__。
- 重连：退出后__，重开后__，原任务/历史是否保留__。
- 发送：路由__，任务增量__，任务ID__，终态/错误码__，目标标题或成品文件名__。

代理收到结果后核对正常应用的任务与成品，分别补齐三行原生证据。隔离popup、桥协议或受控服务器结果不替代这些通过。
