# 0.3.14 Mac 搜索页改造候选

日期：2026-10-15。基线d912698；产品提交5e0d3ba、150b27e。桌面与Sidecar版本0.3.14。仅为本地候选，没有推送或公开发布。

## 改动与可见行为

搜索视图原有两层标题、两个返回按钮、重复空状态与嵌套面板已移除。保留一个“搜索视频”标题、一体化平台/关键词/搜索入口和直接的结果列表。YouTube和Bilibili沿用原真实后端，不新增平台，不重写下载器。

结果展示实际标题、作者、平台、时长、缩略图；缩略图不可达时回退链接图标。缩略图、标题和“打开原网页”均打开真实结果URL，不嵌入假播放界面。明确点击“加入下载”才进入现有下载流程；加入过程中防重复点击，已有任务显示“已在任务中”。失败可重试，没有后台自动入队。

搜索在请求前登记ID，支持取消、输入或切换平台后取消旧请求，并拒绝迟到结果覆盖当前查询。新增search.cancel，后台按独立工作句柄保留引擎忙碌门禁直到线程结束。取消不是立即中断底层TCP；已有网络调用按超时/重试边界结束，取消后不再提交结果或继续后续页。YouTube socket_timeout=8、retries=1、extractor_retries=1；Bilibili沿用6秒socket超时。

关键词、平台、结果与加入中的状态只保存在当前会话内；切换视图返回可继续，不新增持久搜索历史、不读取剪贴板。原搜索完成日志已移除关键词。错误界面使用安全可理解文案，不展示原始异常/凭据。
