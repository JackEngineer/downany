# 0.3.3 Mac 本地连接与恢复升级

本轮从主线 `8e960f81b4e3213722bfcc117bce6fa861b05030` 开始，桌面 / Sidecar 为 0.3.3，扩展为 0.9.3。仅作 Mac 本地安装与提交，未推送、发布或执行 Windows 工作。五人试用已取消，不作为本轮门槛。

## 改动

桌面窗口、设置与断连页显示当前进程和握手服务版本，并提供受控重连。扩展显示已加载插件及实际桌面 / 服务版本，区分后台无响应、服务未就绪、版本不一致和异常端口；无法访问时如实提示可能是应用未运行或浏览器本地网络权限，提供打开应用入口。

发送回执与任务摘要持久化，源网址 / 页内路由只在浏览器会话内保留。原任务重试保留 ID 和选项，并合并同时发生的重试。任务反馈包括进度、安全失败提示和成品文件名；成品定位由桌面按已有任务确认文件存在，不接受任意路径。后台无响应不使用另一条写入通道。

## 边界与剩余项

0.9.3 已打包，尚未由用户在原生 Chrome 加载。原生浏览器重启、应用退出后的扩展唤起、本地网络权限拒绝及重载恢复仍未验证；尊重既有管理页 / 跨应用数据权限拒绝，不绕过。

服务重启后的未知发送结果不能仅凭内存中的服务端请求去重宣称完全幂等；持久化已确认回执与同时点击去重已有验证，未确认结果保留显式核对提示。

本轮网站样本不计入旧正式矩阵，不扩大到跨平台全矩阵。未签名 / 未公证、cloud-only 包保持既有能力边界。所有原始私有证据、下载物与备份留在任务工作区，不进入提交。
