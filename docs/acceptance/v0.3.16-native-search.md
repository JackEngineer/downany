## 实现与权限边界

在既有搜索页增加Dailymotion应用内搜索，保留YouTube、Bilibili应用内搜索及X/抖音/快手网页入口。直接使用匿名公开GET搜索接口，不以网页跳转或webview充当结果。返回规范作品URL、标题、作者、时长、公开封面；每页12条，最多100页。加载更多按URL去重，失败保留已有结果并显式重试，取消及迟到事件按searchId隔离，输入或平台改变后禁止把旧页追加到新查询。

用户点击“加入下载”后才创建任务；Dailymotion显式login_mode=none。解析只读取公开播放器元数据，并拒绝私密、密码、protected_delivery及非点播作品；仅接受限定平台HTTPS媒体地址。下载器清除Cookie、Authorization、浏览器Cookie来源与账号密码，不调用yt-dlp的Dailymotion OAuth提取路径，不生成token或回退鉴权。媒体拒绝不自动重试，不保存临时媒体地址到公开证据。

搜索使用当前仍可匿名访问的legacy API；平台当前推荐版本及未来访问政策可能变化，本轮不能保证legacy永久开放。零费用、无注册、无新凭证、无持久授权、无新协议、无验证码绕过。
