## 实机发现与最终结构

先只读检查用户当前0.3.12窗口并保存截图。问题是管理页左侧48任务、右侧又48大卡片，低频入口与排序堆在左下；顶部添加与设置缺少主次。按照用户明确授权直接实现，不修改独立原型。

1. 顶部统一轻量工具栏：任务、队列、合集、历史、搜索五个稳定导航；右上唯一主操作“新建下载”。设置收入左上Downany应用菜单，Cmd+,保留；Cmd+N打开原对话框。导航支持左右/Home/End，图标均有可读文字或tooltip。
2. 任务模式保留认可的左列表右详情，搜索、状态筛选、排序整合到列表上方，移除左下按钮墙。未知平台继续显示可靠hostname；预览与编辑沿用真实能力。
3. 队列、合集、历史、网站搜索采用全宽视图，不再同时展示左任务列表。统一标题、当前搜索/排序、返回任务模型；队列为紧凑单列表，点击查看进入相应真实详情。合集默认折叠，展开显示原分集及原有真实能力，低频操作收进菜单；只在活动队列显示调度顺序入口。
4. 选中任务或历史后才出现上下文工具栏。暂停/继续仅作用当前选中且适用的任务；取消下载、全部已结束任务记录清理、历史删除/清空均明确范围并确认，不静默删除下载文件。全局清理文案明确包括当前搜索/筛选之外的已结束任务；下载文件、历史与暂停任务保留。原合集显式删除文件选项与确认保持，测试未删除用户文件。
5. 统一行高、间距、状态文案、hover/focus/selected反馈；历史原始英文终态改为可理解中文，操作按钮不再堆叠。管理行重命名使用真实行内输入，Enter保存、Escape取消，避免Electron不支持的prompt。
