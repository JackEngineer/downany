# 0.3.7 Mac 单任务登录策略修复

日期：2026-10-14。已本地构建、安装与实测；未推送或公开发布，未操作 Windows。

## 根因与行为

原任务 dfbbdfac-36ab-494d-adc2-3021da2a1345 使用全局 Chrome 来源，cookie_unavailable 阻断下载。它保存的是公开 X 帖 2109670682598739998 的网页捕获 HLS 直链，媒体 ID 2109670602336321536，而不是帖子 URL。独立公开下载成功说明该媒体可无用户登录取得，但旧应用没有任务级显式选择，重试重新继承来源，Twitter 备用路径也复用登录选项。

新增 inherit / none 策略，旧任务默认为 inherit。添加栏选项仅作用本次添加，接受后复位；任务菜单可单独切换；登录来源不可读错误可点击“不使用登录状态重试此项”，以原 ID 恢复。解析、创建、队列恢复、重试刷新及下载计划统一遵守 none，移除浏览器/Cookie 文件来源和认证请求头。默认来源与其他任务不变。真实需登录或私密内容没有自动匿名降级。

没有读取/导出用户 cookies，未修改全局登录、安全或网络设置，未绕过真实认证。所有继承模式凭据测试使用 mock；不将工程回归算成实际登录验收。该修复证明此公开 X 帖及原捕获任务恢复，不改变 0.3.6 的 YouTube 历史拒绝、Chrome 原生验收和双平台发布缺口，不声称公共稳定发布已就绪。
