> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prepare and verify a Windows x64 Downany 0.2.1 release candidate that delivers the public-copy cleanup already merged into `main`, without pushing, tagging, or publishing.

Synchronize the version carried by the Electron package, Electron-to-Sidecar handshake, and Sidecar protocol; update release-facing documentation; then build the existing cloud-only Windows NSIS path and validate the unpacked application, packaged Sidecar, installer, and extension archive.

**Spec:** `docs/RELEASE.md`

- Do not run onboarding, reset, repair, `npm audit fix`, or dependency upgrades.
- Do not push, create a tag, create/update a GitHub Release, merge, or delete the branch/worktree in this plan.
- A formal release must contain the macOS arm64 DMG, Windows x64 NSIS installer, and Chrome extension ZIP from the same tagged commit.

### Task 4: Build the Extension ZIP and Stop at the Publication Gate

**Files:**
- Generated: `desktop/release/Downany-chrome-extension-0.8.2.zip`

**Interfaces:**
- Consumes: tracked `browser-extension/` contents from the same 0.2.1 candidate tree.
- Produces: extension archive metadata suitable for the eventual three-asset Release.

- [x] **Step 1: Create the extension archive without tests or development metadata**

  Run from the repository root:

  ```powershell
  Add-Type -AssemblyName System.IO.Compression.FileSystem
  $source = (Resolve-Path -LiteralPath 'browser-extension').Path
  $destination = Join-Path (Resolve-Path -LiteralPath 'desktop/release').Path 'Downany-chrome-extension-0.8.2.zip'
  if (Test-Path -LiteralPath $destination) { Remove-Item -LiteralPath $destination -Force }
  $archive = [System.IO.Compression.ZipFile]::Open($destination, [System.IO.Compression.ZipArchiveMode]::Create)
  try {
      $trackedFiles = @(git ls-files -- 'browser-extension')
      foreach ($trackedFile in $trackedFiles) {
          $relative = $trackedFile.Substring('browser-extension/'.Length)
          if ($relative -like '*.test.js' -or
              [System.IO.Path]::GetFileName($relative) -eq '.DS_Store' -or
              $relative -match '(^|[\\/])\.' -or
              $relative -match '(^|[\\/])__MACOSX([\\/]|$)') {
              continue
          }
          $fullPath = Join-Path $source $relative
          [System.IO.Compression.ZipFileExtensions]::CreateEntryFromFile(
              $archive,
              $fullPath,
              $relative.Replace('\\', '/'),
              [System.IO.Compression.CompressionLevel]::Optimal
          ) | Out-Null
      }
  } finally {
      $archive.Dispose()
  }
  ```
