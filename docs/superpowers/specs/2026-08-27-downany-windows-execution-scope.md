# Downany Windows 执行范围调整

- 日期：2026-08-27
- 用户指令：`mac你不用管`；随后明确 `继续往后面做，不用手动验收`。
- 适用目标：继续按 `v0.2.4 → v0.2.5 → v0.3.0` 逐级形成稳定版本，不直接跳版本。

## 当前有效范围

1. 本任务只负责 Windows x64 桌面端、Python Sidecar、Windows 使用链路中的 Chrome 扩展，以及相应文档与交付验证。
2. 不执行 macOS 开发、构建、DMG 检查或 Mac 实机验收，不要求用户提供 Mac；这些工作不再阻塞本任务的版本推进或完成判定。
3. 保留已有 macOS 源码、构建脚本、CI 配置、历史资产和历史证据。没有执行的 Mac 验收仍记为“本任务不负责/未执行”，不得改成通过，也不得据此宣称 Mac 稳定。
4. 本任务交付集合为同一源码对应的 Windows NSIS 与 Chrome 扩展 ZIP；不等待或代为生成 DMG，不把旧版本 DMG 拼入新版本。任何已存在的 Mac 资产都不删除或覆盖。
5. 不再要求用户操作窗口、重启系统或完成人工验收；安装态可见旅程不再是继续开发或完成本地候选的前置条件。改以真实存储、协议、组件、恢复场景、媒体管线、生产构建和隔离包级自动化验证相应合同。未执行的人工检查记为“按用户要求不执行”，不得宣称已经通过实机可见验收。
6. 从当前 `v0.2.4` 候选的已记录源码继续 `v0.2.5`，重新跑自动化基线，不再等待手动重启。若集成尚未授权，允许以候选 HEAD 加其已核对未提交差异建立独立的本地工作区，并记录来源、逐文件校验和继承差异；不修改原候选、不将复制基线称为已合并。后续 `v0.3.0` 同样按逐阶段本地验证推进，不要求提前提交或合并来解除开发阻塞。
7. 本次范围调整不授权本地提交、合并、推送、tag、远程 CI、上传、公开 Release、网站部署或清理。公开发布时明确 Windows 范围，不以排除 Mac 为由省略 Windows/扩展的同源、版本、大小、SHA256 和匿名下载验证。

## 与原计划的关系

本文件是用户对执行范围的最新明确调整，优先于此前规格和计划中的 macOS、Apple Silicon、双平台同时验收、DMG 必需、三资产必需、人工/实机验收前置条件，以及仅为等待集成而阻塞本地后续实现的步骤。历史事实与现有跨平台实现保留；未标明历史的执行步骤以本文件为准。没有改变 Windows 功能目标，不跳过自动化验证，也没有把未执行的人工检查标为通过。
