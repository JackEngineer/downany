# 资源下载器开发方案

## 1. 项目背景
基于 `yt-dlp` 开发一款 macOS 平台的通用资源下载器，旨在提供简单易用的图形化界面，降低命令行工具的使用门槛。

## 2. 技术选型
*   **编程语言**: Python 3.9+
*   **核心库**: `yt-dlp` (下载引擎)
*   **多媒体处理**: `ffmpeg` (必须安装，用于合并流)
*   **GUI 框架**: `PyQt6` (建议) 或 `Tkinter`
*   **打包工具**: `PyInstaller`

## 3. 核心功能
*   **基础下载**: 支持单个视频 URL 下载。
*   **格式控制**: 自动合并最佳视频流和音频流 (Video+Audio)，输出 MP4。
*   **进度反馈**: 实时显示下载百分比、速度和剩余时间。
*   **配置管理**:
    *   下载目录选择
    *   代理设置 (解决网络问题)
    *   Cookie 加载 (解决会员/登录限制)

## 4. 模块设计
### 4.1 Core Engine (`src/core/downloader.py`)
*   封装 `yt_dlp.YoutubeDL` 类。
*   注册 `progress_hooks` 处理回调数据。
*   异常捕获与日志记录。

### 4.2 UI Layer (`src/ui/`)
*   主窗口布局。
*   信号与槽机制 (Signals/Slots) 连接 UI 与后台下载线程。
*   防止界面卡死的异步处理 (QThread)。

## 5. 开发计划
1.  **环境搭建**: 配置 Python 虚拟环境，安装依赖。
2.  **核心封装**: 编写不带 UI 的 Python 类，测试下载功能。
3.  **UI 开发**: 绘制界面，绑定事件。
4.  **集成测试**: 联调 UI 与核心功能。
5.  **打包发布**: 生成 macOS 可执行文件。

## 6. 注意事项
*   确保系统已安装 `ffmpeg` 并在 PATH 中。
*   网络请求需处理超时和重试机制。
*   需遵守目标网站的使用条款和版权法规。
