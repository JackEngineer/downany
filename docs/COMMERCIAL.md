本文档为 **Downany · 百纳** 官网、试用与正式许可的占位说明，具体条款以正式发布为准。

## 产品定位

- macOS 原生体验的视频下载工具（Electron + Sidecar + yt-dlp）
- 面向个人用户与小团队，支持主流视频站点及 yt-dlp 兼容的 1700+ 站点
